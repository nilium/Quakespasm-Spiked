Quakespasm-Spiked Fork
===

This is a fork of [Quakespasm-Spiked][qss] with changes to use the Meson build system and any code changes I personally want to make.
It's not intended to be a general purpose build of the engine with compatibility for everything.
For that you should continue to use the original source or another fork.
I just want to treat it as a place to toy with the engine and build things on for fun.

Note that some old build files remain around while the Meson conversion is in progress.
Those will be removed as I get time to build and test on other platforms.
Support for less common systems or systems I don't have a reason to use won't be maintained (though Haiku may be left in because I think it's neat).

[qss]: https://github.com/Shpoike/Quakespasm
